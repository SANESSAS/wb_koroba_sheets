# WB Koroba Sheets

Дополнение для Google Таблиц, которое автоматизирует заполнение ID по коробам в таблицах для работы с Wildberries.

Сделал его, чтобы не переносить ID вручную по десяткам колонок.

**Сайт проекта:** https://sanessas.github.io/wb_koroba_sheets/

## Что делает

Скрипт:

- находит лист `ID`;
- берет значения из колонки `A` сверху вниз;
- находит на листе `Готовые данные` колонки вида `Короб 1`, `Короб 2`, `Короб 3` и т.д.;
- сохраняет физический порядок колонок слева направо;
- записывает ID в строку 2;
- не трогает остальные области листа.

Пример:

```text
ID
12345
67890
54321
```

Если на листе `Готовые данные` короба стоят так:

```text
Короб 8 | Короб 3 | Короб 15
```

то заполнение идет именно слева направо:

```text
12345 → Короб 8
67890 → Короб 3
54321 → Короб 15
```

Номер короба не используется для сортировки.

## Требования к таблице

Нужны два листа.

### `ID`

ID должны находиться в колонке `A`. Пустые ячейки пропускаются.

### `Готовые данные`

Названия коробов должны находиться в строке 4 и иметь формат:

```text
Короб 1
Короб 2
Короб 3
```

Также поддерживается вариант без пробела:

```text
Короб1
Короб2
```

ID записываются в строку 2 соответствующих колонок.

## Использование

Основная функция:

```javascript
zapolnitShkKorobov()
```

В версии Google Sheets Editor Add-on команда находится в меню:

```text
Расширения → WB Koroba Sheets → Заполнить ID по коробам
```

После запуска скрипт показывает количество найденных ID и коробов.

## Проверки

Скрипт останавливается с ошибкой, если:

- не найден лист `ID`;
- не найден лист `Готовые данные`;
- колонка `A` на листе `ID` пустая;
- в строке 4 не найдено ни одного короба;
- ID больше, чем найденных коробов.
