Заполнение ID по коробам в Google Таблицах

WB Koroba Sheets — дополнение для Google Таблиц на Apps Script. Оно берёт список ID с листа ID, находит колонки с заголовками Короб N и записывает значения по порядку этих колонок слева направо.

Исходный код на GitHub Поддержка Конфиденциальность

Как работает

  1. Подготовьте список ID

    На листе ID разместите значения в колонке A. Читаются непустые значения сверху вниз.

  2. Проверьте заголовки коробов

    На листе Готовые данные в строке 4 должны быть заголовки вида Короб 1, Короб 2 и так далее.

  3. Запустите команду

    Дополнение записывает ID в строку 2 найденных колонок и показывает сообщение о результате.

Расширения → WB Koroba Sheets → Заполнить ID по коробам

Структура таблицы

Сценарий привязан к конкретной структуре — это делает результат предсказуемым.

Лист «ID»
Список ID в колонке A.
Лист «Готовые данные»
Заголовки коробов в строке 4.
Формат заголовка
Короб 1, Короб2, Короб 15 — совпадение по образцу «Короб N».
Строка результата
ID записываются в строку 2 найденных колонок.
Порядок записи
По фактическому расположению колонок слева направо.

Ограничения

  • Существующие значения перезаписываются. Значение в строке 2 найденной колонки заменяется новым ID.
  • Лишние короба не очищаются. Если новый список ID короче предыдущего, старые значения в оставшихся коробах остаются на месте — их нужно удалить вручную.
  • ID не должно быть больше, чем коробов. В этом случае запись не начинается и выводится ошибка.
  • Только описанный сценарий. Дополнение не перестраивает таблицу и не работает с другой структурой листов.

Перед запуском в рабочей таблице сохраните копию документа или убедитесь, что можете вернуться к предыдущей версии через историю изменений Google Таблиц.

Поддержка и конфиденциальность

  • Поддержка — подготовка таблицы, запуск и разбор типовых сообщений об ошибках.
  • Issues на GitHub — сообщить о проблеме.
  • Политика конфиденциальности — какие данные читает дополнение. Содержимое таблиц не отправляется на сервер проекта или в отдельную базу данных: всё выполняется средствами Google Apps Script.
