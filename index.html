Заполняет ID по коробам без ручного копирования

WB Koroba Sheets берет список ID с отдельного листа, находит колонки Короб N и записывает значения по их фактическому порядку слева направо.

Возможности

Только нужная автоматизация

Дополнение не перестраивает таблицу и не пытается угадывать порядок по номерам коробов. Оно выполняет один понятный сценарий.

A

Читает список ID

Берет непустые значения из колонки A листа ID сверху вниз.

#

Находит «Короб N»

Проверяет строку 4 листа Готовые данные и находит подходящие заголовки.

→

Сохраняет порядок

Первый ID идет в первый найденный короб слева, второй — в следующий и так далее.

✓

Проверяет данные

До записи проверяет наличие нужных листов, коробов и достаточного количества колонок.

Как работает

Три шага от списка до результата

01

Подготовить ID

На листе ID разместить значения в колонке A. Пустые строки между значениями можно оставлять.

02

Проверить короба

На листе Готовые данные в строке 4 должны быть заголовки Короб 1, Короб 2 и т.д.

03

Запустить команду

В меню дополнения выбрать «Заполнить ID по коробам». После выполнения появится итоговое сообщение.

Структура таблицы

Что должно быть на своих местах

Сценарий привязан к конкретной структуре. Это делает результат предсказуемым и позволяет быстро понять причину ошибки.

01
Лист «ID»

Значения находятся в колонке A.

02
Лист «Готовые данные»

Заголовки коробов находятся в строке 4.

03
Формат заголовка

Короб 1, Короб2, Короб 15 и т.п.

04
Строка результата

ID записываются в строку 2 найденных колонок.

Пример

Порядок колонок важнее номера

12345→Короб 8
67890→Короб 3
54321→Короб 15

Даже если номера коробов идут не по порядку, дополнение не сортирует их и сохраняет физическое расположение колонок.

Перед использованием

Что важно учитывать

01 Значение в строке 2 найденной колонки будет перезаписано новым ID.

02 Если новый список ID короче предыдущего, значения в оставшихся коробах автоматически не очищаются.

03 Если ID больше, чем найденных коробов, запись не начинается и выводится ошибка.

Конфиденциальность

Без внешнего сервера проекта

Содержимое таблиц не отправляется в отдельную базу данных или на собственный сервер. Работа выполняется средствами Google Apps Script.
