Политика конфиденциальности

Какие данные нужны WB Koroba Sheets для работы, для чего они используются и что с ними происходит.

WB Koroba SheetsПоследнее обновление: 3 сентября 2026 года

1. Общие положения

WB Koroba Sheets — дополнение для Google Таблиц, предназначенное для автоматизации заполнения ID по колонкам коробов. Обработка данных начинается только после запуска команды пользователем и ограничена текущей открытой таблицей.

2. Какие данные обрабатываются

Для выполнения основной функции дополнение может читать:

  • названия листов текущей Google Таблицы;
  • значения из колонки A листа «ID»;
  • заголовки строки 4 листа «Готовые данные»;
  • название текущей таблицы для отображения результата пользователю.

После проверки структуры дополнение записывает ID в строку 2 найденных колонок коробов.

3. Для чего используется доступ

Доступ к Google Sheets используется только для основной функции проекта: чтения подготовленного списка ID, поиска колонок Короб N, записи результата и вывода сообщения о выполнении.

Данные Google не используются для рекламы, продажи данных, построения пользовательских профилей или иных целей, не связанных с работой дополнения.

4. Хранение и передача данных

WB Koroba Sheets не использует собственный сервер или отдельную базу данных для хранения содержимого Google Таблиц.

Код проекта не отправляет содержимое таблиц сторонним сервисам. Выполнение происходит средствами Google Apps Script и Google Sheets в инфраструктуре Google.

5. Данные сайта

Сайт проекта размещен на GitHub Pages. В код сайта не добавлены собственные системы аналитики, рекламные модули, формы сбора данных или пиксели отслеживания.

При посещении сайта применяются стандартные технические правила и журналы инфраструктуры GitHub Pages, которые находятся под управлением GitHub.

6. Google API Services User Data Policy

Использование информации, полученной через Google APIs, ограничено функциональностью дополнения и должно соответствовать Google API Services User Data Policy, включая требования Limited Use.

7. Изменения политики

Если изменится функциональность дополнения, набор запрашиваемых разрешений или порядок обработки данных, эта страница будет обновлена. Дата актуальной редакции указана в верхней части страницы.

8. Контакты

Вопросы по конфиденциальности, доступу к данным и работе проекта можно направить через GitHub.
