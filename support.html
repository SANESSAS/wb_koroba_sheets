Поддержка

Подготовка таблицы, запуск дополнения и решения типовых ошибок.

Перед запуском

  • Есть лист «ID», значения находятся в колонке A.
  • Есть лист «Готовые данные».
  • В строке 4 находятся заголовки вида «Короб 1», «Короб 2» и так далее.
  • Количество ID не превышает количество найденных колонок коробов.

Как запустить

Команда находится в меню Google Таблиц:

Расширения → WB Koroba Sheets → Заполнить ID по коробам

После выполнения появится сообщение с количеством обработанных ID и найденных позиций коробов.

Как определяется порядок

Дополнение не сортирует короба по номеру. Первый ID записывается в первую подходящую колонку слева, второй — в следующую и так далее.

Например, заголовки Короб 8 | Короб 3 | Короб 15 останутся именно в таком порядке, и ID распределятся по ним слева направо.

Типовые сообщения

Не найден лист «ID»
Проверьте название листа. Регистр букв и случайные пробелы по краям не важны.
Колонка A пустая
На листе «ID» должен быть хотя бы один непустой ID в колонке A.
Не найдено «Короб N»
Проверьте строку 4 листа «Готовые данные» и формат заголовков.
ID больше, чем коробов
Добавьте недостающие колонки коробов или уменьшите список ID перед запуском. Запись не начинается.

Что происходит с существующими значениями

Для найденных коробов новые ID записываются в строку 2. Если там уже было значение, оно будет заменено.

Если новый список ID короче предыдущего, дополнение не очищает оставшиеся значения в более правых коробах автоматически. При необходимости их нужно удалить вручную.
