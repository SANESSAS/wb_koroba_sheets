Поддержка WB Koroba Sheets

Краткая инструкция по подготовке таблицы, запуску дополнения и решению типовых ошибок.

Перед запуском

Проверьте структуру таблицы:

  • есть лист с названием «ID»;
  • ID находятся в колонке A этого листа;
  • есть лист «Готовые данные»;
  • названия коробов находятся в строке 4 и имеют вид «Короб 1», «Короб 2» и т.д.;
  • количество ID не превышает количество найденных коробов.

Как запустить

Расширения → WB Koroba Sheets → Заполнить ID по коробам

После выполнения появится сообщение с количеством обработанных ID и найденных позиций коробов.

Типовые сообщения

Не найден лист «ID»

Проверьте название листа. Регистр букв и случайные пробелы по краям не важны.

Колонка A пустая

На листе «ID» должен быть хотя бы один непустой ID в колонке A.

Не найдено «Короб N»

Проверьте строку 4 листа «Готовые данные» и формат заголовков.

ID больше, чем коробов

Нужно добавить недостающие колонки коробов или уменьшить список ID перед запуском.

Как определяется порядок

Дополнение не сортирует короба по номеру. Первый ID записывается в первую подходящую колонку слева, второй — в следующую и так далее.

Например: Короб 8 | Короб 3 | Короб 15 остаются именно в таком порядке.

Сообщить о проблеме

Если ошибка повторяется при корректной структуре таблицы, можно создать Issue в репозитории проекта или написать через профиль GitHub.
