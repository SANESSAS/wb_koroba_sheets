Принцип работы

Три простых действия

Логика специально сделана предсказуемой: дополнение не перестраивает таблицу и работает только с нужными ячейками.

01ID

Читает список

Берет непустые значения из колонки A листа ID сверху вниз.

02Короба

Находит колонки

Проверяет строку 4 листа Готовые данные и находит заголовки формата Короб N.

03Готово

Записывает ID

Заполняет строку 2 в физическом порядке колонок слева направо и показывает результат.

Структура таблицы

Что нужно подготовить

Дополнение рассчитано на конкретную структуру, поэтому перед запуском легко проверить, что всё находится на своих местах.

A

Лист «ID»

ID находятся в колонке A. Пустые ячейки пропускаются.

4

Заголовки коробов

На листе «Готовые данные» они находятся в строке 4.

2

Строка результата

ID записываются в строку 2 соответствующих колонок.

✓

Проверки перед записью

Если листы или короба не найдены, выполнение останавливается с понятным сообщением.

Запуск

Команда прямо в меню таблицы

После установки дополнение запускается без отдельного сайта, приложения или программы.
