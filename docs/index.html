Google Sheets Add-on

ID по коробам — без ручного переноса

WB Koroba Sheets переносит ID из отдельного листа в нужные колонки коробов и сохраняет фактический порядок колонок слева направо.

Открыть на GitHub Посмотреть принцип работы
Работает прямо в Google Таблицах Без отдельной программы Без собственного сервера
Готовые данные пример
Короб 8Короб 3Короб 15
ID123456789054321
12345первый ID
→
Короб 8первая колонка слева

Номера коробов не сортируются. Используется реальный порядок колонок в таблице.

Зачем это нужно

Одна команда вместо ручного заполнения

Инструмент сделан для таблиц, где список ID уже подготовлен, а дальше его нужно разнести по колонкам Короб N. Скрипт берет эту рутину на себя и перед записью проверяет структуру таблицы.

Как работает

Три шага

01

Читает ID

Берет непустые значения сверху вниз из колонки A листа ID.

02

Находит короба

Ищет в строке 4 листа Готовые данные заголовки формата Короб N.

03

Записывает результат

Заполняет строку 2 слева направо и не перезаписывает остальные области листа.

Запуск

Команда находится в меню Google Таблиц

Расширения→WB Koroba Sheets→Заполнить ID по коробам

Структура таблицы

Что должно быть подготовлено

A

Лист «ID»

Список ID находится в колонке A. Пустые строки пропускаются.

4

Строка с коробами

На листе «Готовые данные» заголовки коробов находятся в строке 4.

2

Строка результата

ID записываются в строку 2 соответствующих колонок коробов.

✓

Встроенные проверки

Если листы, короба или количество позиций не совпадают, выполнение останавливается с понятной ошибкой.

Технически

Google Apps Script

Дополнение работает внутри Google Sheets через Google Apps Script. Проект не использует собственный сервер или отдельную базу данных для содержимого таблиц.
