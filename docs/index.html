Google Sheets Add-on

WB Koroba Sheets

Дополнение для Google Таблиц, которое автоматизирует заполнение ID по коробам при работе с таблицами Wildberries.

GitHub Политика конфиденциальности

Что делает

Я сделал этот инструмент, чтобы не переносить ID вручную по большому количеству колонок.

  • берёт ID из колонки A листа ID;
  • находит на листе Готовые данные колонки вида Короб N;
  • сохраняет фактический порядок коробов слева направо;
  • записывает ID в строку 2 соответствующих колонок;
  • останавливает выполнение, если структура таблицы не соответствует ожидаемой.

Как используется

После установки дополнения команда запускается прямо из меню Google Таблиц. Дополнительные программы и отдельный интерфейс не нужны.

Расширения → WB Koroba Sheets → Заполнить ID по коробам

Требования к таблице

В книге должны быть листы ID и Готовые данные. ID находятся в колонке A, заголовки коробов — в строке 4, а результат записывается в строку 2.

О проекте

Проект работает на Google Apps Script и предназначен для Google Sheets. Обработка выполняется внутри открытой таблицы.

WB Koroba Sheets — независимый проект и не является официальным продуктом Wildberries.
