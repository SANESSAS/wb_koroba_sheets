Какие данные обрабатываются

Дополнение работает с данными открытой Google Таблицы только в объёме, необходимом для выполнения выбранной команды. В частности, оно читает ID и заголовки коробов и записывает результат в соответствующие ячейки.

Хранение и передача данных

Проект не использует собственный сервер или базу данных для хранения содержимого таблиц. Код дополнения не отправляет данные таблиц сторонним сервисам.

Обработка выполняется средствами Google Apps Script и Google Sheets в инфраструктуре Google.

Доступ к Google Sheets

Для работы дополнению требуется доступ к Google Sheets, необходимый для чтения и изменения данных в таблице, где пользователь запускает команду.

Сайт проекта

Сайт проекта не содержит аналитики, рекламных систем или собственных механизмов отслеживания пользователей.

Изменения политики

Если функциональность проекта или способ обработки данных изменится, эта страница будет обновлена.
