Политика конфиденциальности

Здесь описано, какие данные нужны дополнению для работы и что с ними происходит.

WB Koroba SheetsПоследнее обновление: 3 сентября 2026 года

1. Общие положения

WB Koroba Sheets — дополнение для Google Таблиц, предназначенное для автоматизации заполнения ID по колонкам коробов. Дополнение обрабатывает только те данные открытой таблицы, которые необходимы для выполнения команды, запущенной пользователем.

2. Какие данные обрабатываются

При запуске дополнение может читать:

  • названия листов открытой Google Таблицы;
  • значения из колонки A листа «ID»;
  • заголовки строки 4 листа «Готовые данные»;
  • название текущей таблицы для отображения результата пользователю.

После проверки структуры дополнение записывает ID в соответствующие ячейки строки 2.

3. Для чего используется доступ

Доступ к Google Sheets используется исключительно для выполнения основной функции дополнения: чтения подготовленных ID, поиска колонок коробов и записи результата в текущую таблицу.

Дополнение не использует данные Google для рекламы, формирования пользовательских профилей или иных целей, не связанных с его основной функцией.

4. Хранение и передача данных

Проект не использует собственный сервер или отдельную базу данных для хранения содержимого Google Таблиц. Код дополнения не отправляет содержимое таблиц сторонним сервисам.

Выполнение происходит средствами Google Apps Script и Google Sheets в инфраструктуре Google.

5. Ограниченное использование данных Google

Использование информации, полученной через Google APIs, ограничено функциональностью дополнения и соответствует требованиям Google API Services User Data Policy, включая требования Limited Use.

6. Сайт проекта

Сайт WB Koroba Sheets размещён на GitHub Pages. На сайте не установлены собственные системы аналитики, рекламные модули, пиксели отслеживания или формы сбора персональных данных.

7. Изменения политики

Если изменится функциональность дополнения, запрашиваемые разрешения или порядок обработки данных, эта страница будет обновлена.
