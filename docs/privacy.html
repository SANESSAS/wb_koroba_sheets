Общие положения

WB Koroba Sheets — дополнение для Google Таблиц, предназначенное для автоматизации заполнения ID по колонкам коробов. Дополнение работает только с данными, необходимыми для выполнения выбранной пользователем команды.

Какие данные обрабатываются

При запуске команды дополнение читает значения из открытой Google Таблицы: список ID, названия листов и заголовки колонок коробов. После проверки структуры таблицы оно записывает ID в соответствующие ячейки.

Дополнение не предназначено для сбора персональных данных пользователя и не формирует собственные пользовательские профили.

Хранение и передача данных

Проект не использует собственный сервер или отдельную базу данных для хранения содержимого Google Таблиц. Код дополнения не отправляет содержимое таблиц сторонним сервисам.

Выполнение происходит средствами Google Apps Script и Google Sheets в инфраструктуре Google.

Доступ к Google Sheets

Для выполнения своей функции дополнению требуется доступ к Google Sheets в объёме, необходимом для чтения и изменения данных в таблице, где пользователь запускает команду.

Доступ используется для выполнения действий, инициированных самим пользователем.

Сайт проекта

Сайт WB Koroba Sheets размещён на GitHub Pages. На сайте проекта не установлены собственные системы аналитики, рекламные модули или дополнительные механизмы отслеживания посетителей.
